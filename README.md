# xx理论.skill

把一个物品、一段经历，写成有辨识度的互联网生活理论。

> 你提供生活，我们负责开宗立派。

中文创作 Skill，支持名称、主张、原则、金句与口播。默认正经胡说，也支持认真践行、犀利宣言和大水式宣讲。无需额外 API、脚本或训练。

## 看看效果

**折叠凳**

> 折叠凳一打开，休息区当场成立。去公园，你有观景位；等朋友，你有接待处。一把凳子，走到哪，把基础设施带到哪。

**归碟理论**

> 一串钥匙负责打开很多地方，回家就认这一个地方。我的要求很简单：出门之前，把钥匙从碟子里拿起来就走。

以上为项目原创试写节选，完整稿与夹灯案例见 [案例集](xx-theory/references/examples.md)。目前是 v0.1 草案，已有项目提出者的语感反馈；独立评测与宿主兼容性仍待验证。

## 怎么用

**直接聊天**：复制 [PROMPT.md](PROMPT.md)，再发送物品或经历，体验轻量版。

**作为 Skill**：将整个 [xx-theory/](xx-theory/) 目录放入所用工具的技能目录，保留 references/，入口为 [SKILL.md](xx-theory/SKILL.md)。加载方式以该工具说明为准。在支持以下调用方式的工具中：

~~~text
$xx-theory 给雨伞创立一个理论，正经胡说，写成30秒口播。
$xx-theory 我想周末发呆，别写成成功学。只给一句话。
$xx-theory 给保温饭盒写一段大水式宣讲，100字左右，只要口播。
~~~

自然语言说明文风、篇幅、目标读者或要保留的名字与立场即可。生成稿可以继续修改；文学夸张不等于科学或功效证明。
