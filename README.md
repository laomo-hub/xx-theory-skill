# xx理论.skill

把一个物品、一段经历，写成一种让人想转发的互联网生活理论。

> 你提供生活，我们负责开宗立派。

这是一个中文创作 Skill 的 v0.1 草案。支持从物品特点或个人经历出发，生成名称、核心主张、原则、金句与口播。无须额外 API、脚本或训练；需要一个能执行文字指令的大语言模型。

以下为本项目原创试写。其中三篇在本聊天中获得项目提出者正向反馈，完整版本与首轮三篇待改稿见 [校准记录](xx-theory/references/calibration.md)。这些是定向语感反馈，不代表独立评测或传播效果。

> 折叠凳一打开，休息区当场成立。去公园，你有观景位；等朋友，你有接待处。一把凳子，走到哪，把基础设施带到哪。

**夹灯理论｜反馈：第三个可以（第二轮）**

> 自己站在边上，照亮整个桌面。什么叫格局？什么叫组织能力？这就是夹式台灯。

**归碟理论｜反馈：第五个还可以（新题轮）**

以上为稿件节选。

## 怎么用

### 直接聊天

复制 [PROMPT.md](PROMPT.md) 的提示词到聊天窗口，再发送物品或经历。这是轻量体验版。

### 作为 Skill

完整技能目录是 [xx-theory/](xx-theory/)，入口为 [SKILL.md](xx-theory/SKILL.md)。将整个目录放入所用工具的技能目录，保留 references/。安装位置与加载方式以该工具的说明为准。

在支持美元符号技能调用的工具中，可以试用：

~~~text
$xx-theory 给雨伞创立一个理论，正经胡说，写成30秒口播。
$xx-theory 我一直留着快递箱，因为觉得以后可能用得上。帮我形成一个学派。
~~~

本仓库尚未完成不同宿主、不同模型的安装与行为兼容性验证。

要使用“大水式宣讲”，请在输入中明确指定，例如：

~~~text
$xx-theory 给保温饭盒写一段大水式宣讲，100字左右，只要口播。
~~~

生成结果是候选稿，可以继续反馈具体问题。

## 可选控制

直接用自然语言描述，不要求填写表单。

- 输入：一个物品、一种习惯，或一段个人经历。
- 文风：认真践行 / 正经胡说 / 犀利宣言；另有基于真实文稿整理的大水式宣讲模式。默认正经胡说。
- 输出：完整理论 / 一句话 / 仅命名 / 社交短文 / 口播。
- 补充：目标读者、长度、想保留的观点。用户指定的名字与立场优先。

这是文学包装与玩梗工具。幽默来自具体观察和夸张推演，不给虚构主张编造科学背书。

## 一起贡献

可以通过[素材投稿表单](https://github.com/laomo-hub/xx-theory-skill/issues/new?template=sample.yml)提供样本。优先补充不同作者、不同理论的表达；填写原链接和自己的摘要，长文稿可以摘录关键片段。

可以提交真实样本来源、原创案例、失败输出，或更好的生成规则。提交样本时请注明输入、输出、风格、为什么好或不好；第三方内容保留来源，优先贡献自己的总结与分析。

评测方法见 [evals/README.md](evals/README.md)。建议先比较“同样输入，普通提示词和此 Skill 的结果”，再决定增加哪些规则。
