# 表达机制与文风

这是原创创作指南；术语是项目内部的拆解方式，不宣称为学术模型。

## 四种可选机制

根据输入选择一种，避免每次叠满全部机制。

| 机制 | 适合的输入 | 生成方向 |
| --- | --- | --- |
| 动作变仪式 | 出门带袋、收桌面 | 给一个小动作赋予可复述的意义 |
| 物理特点变比喻 | 雨伞收放、拉链开合 | 由物品特点延伸到处事态度 |
| 限制变立场 | 小碗容量、旧手机储存 | 从有限条件中提炼一种选择 |
| 重新命名经历 | 等消息、保留纸箱 | 把用户真实经验概括为一个主张 |

不是所有物品都需要“解决焦虑”。可以写方便、好看、好笑、节省精力，甚至只是一种偏爱。保持物品的实际用途，别先想大道理再硬塞物品。

## 三种文风

### 认真践行

观察具体、语气克制，给一个容易做到的小动作。金句来自观察的准确，不靠假装科学。

输入“周日整理桌面”：围绕明早能直接开始第一件事展开，避免承诺消除焦虑或改变命运。

### 正经胡说（默认）

用一条像模像样的定义承接一个荒诞推论。可使用“第一公理、入门仪式、学派认为”，但整篇不要写成条款。夸张显然属于玩笑，不借真实权威骗取可信度。

输入“帆布袋”：从把零散物品集中起来推导出双手自由，再给收拾小票这一具体动作。

### 犀利宣言

短句、明确立场、有节奏。矛头针对某种行为或处境，不辱骂人群。可以拒绝无意义的忙碌，但不要对所有输入都套“拒绝内耗、夺回人生”。

输入“已读不回”：围绕停止反复点开聊天窗口展开，不断言对方的动机。

## 命名

名字应让人能联想到对象、动作或立场。两到六个字是方便复述的起点，不是硬性限制。“大xx”“留xx”“xx学派”只是选项。用户指定名称优先。

金句别只是把核心主张换两个同义词。口播应有场景、观点和落点，不要复述整张原则清单。避免连续使用“这不是X，而是Y”；少用赋能、底层逻辑、认知跃迁等套话，除非用户明确要求戏仿。

## 大水式宣讲（可选）

适用于用户要求“大水理论那种感觉”“教父式宣讲”或把物品包装成身份主张。基于同一作者系列18篇不同文稿的观察，素材口径见 [来源索引](sources.md)。以下是创作选项，不要求复现原作者全部写法。

普通对象被坚定拥护，实际特点逐步获得夸张的生活意义。选择对象一个有力特点，再选一条主路径：

| 路径 | 展开方式 |
| --- | --- |
| 特点升级 | 具体便利 → 做事方式 → 夸张身份主张 |
| 对照立论 | 两种选择 → 同一尺度比较 → 鲜明立场 |
| 文化替换 | 围绕对象，连续改写两三个有关联的场景或称呼 |
| 轶事铺演 | 用明确虚构的角色或情景，展示学派如何解释一切 |

开头先下结论、立标准或提出改名倡议；正文给容易跟上的细节，再安排一次明显过大的文学推演；结尾落到相关动作与顺口短句。不必硬凑三点，也不必每篇都用公理标题。

强者、小众等身份词需有对象细节支撑。让同一核心画面持续发展：场景、比喻和身份主张能接上，而非最后补一句“有头脑”。修订时先换支点或路径，别只增加宏大词。

系列可以保留核心立场，再用新场景展开；单篇不要反复说同一个理由，也不要机械套“健康、省钱、成功”。已有正反例见 [案例集](examples.md)，借鉴推演方式，不照抄“基础设施”或“组织能力”。
